# Open call «Фрактальной Одиссеи» 2026 — первый сайт matema-fest.ru и приём заявок

<!-- gen:podrobno — пишет генератор описаний; правки сюда пропадут, править ответы анкеты -->

Первый сайт фестиваля на домене `matema-fest.ru`, собранный, чтобы позвать участников. Open call — открытый набор станций, инсталляций и выступлений в программу «Фрактальной Одиссеи» 23 мая 2026. Когда программа собралась, форму убрали, а домен отдали основному сайту `matema-fest`.

`index.html` — заглушка «Фрактальная Одиссея, 23 мая, Чистые пруды, 18+» с кнопкой Open Call. `opencall2026/index.html` — лендинг: что ищем (опыт, который нельзя получить дома), три формата (станция на час, инсталляция на весь вечер, выступление на 15–45 минут), пять направлений с примерами, спикеры и партнёры; наверху теперь стоит «Open call завершён». Рядом политика обработки персональных данных, написанная под форму, и «Галерея самоподобных форм». README объясняет, где лежит старая версия с формой и как её вернуть.

Анкета с прогрессом сверху и окном предпросмотра отправляла заявку в Google Apps Script, заявки копились в Google-таблице. Версия с формой сохранена в ветке `archive/open-call-with-form`. Сайт статический и публикуется на GitHub Pages из `main`.

Сайт жил около месяца, с 20.04 по 15.05.2026. Лендинг с формой почти без изменений повторён в `matema-fest/opencall/`, так что на живом домене open call теперь показывает основной сайт. Сами заявки в репозитории не хранятся; в `matema-fest/festival-data.js` для них есть раздел `applications`.

Сюда идти за текстом приглашения участников (форматы, направления, что ищем) и за образцом формы-заявки на событие. Связи: `matema-fest` (преемник домена, копии `opencall/` и `gallery/`), `gallery` и `ankety`, где теперь идёт сбор заявок.
