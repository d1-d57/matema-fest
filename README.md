# Сайт фестиваля «Фрактальная Одиссея» (matema-fest.ru): лекции, квиз, галереи, программа

<!-- gen:podrobno — пишет генератор описаний; правки сюда пропадут, править ответы анкеты -->

Сайт фестиваля научпопа «Фрактальная Одиссея» (Matema-фест 2026): 23 мая, Чистые пруды, днём библиотека имени Достоевского, вечером и ночью клуб «Лахесис». Тема года — 50 лет слову «фрактал». Сайт живёт на GitHub Pages с доменом `matema-fest.ru`, пуш в `main` выходит в сеть за минуту-полторы. Здесь не только лендинг, но и лекции фестиваля, квиз, выставка и рабочий инструмент для составления программы.

Главная `index.html` с интерактивным папоротником Барнсли в расписании и Аполлониевой упаковкой в программе. `festival-data.js` — база программы: 87 событий, 53 временных слота, 5 площадок; `programmer.html` — редактор этой базы в браузере. `lectures/` — три лекции-презентации: «Красота математики» А. М. Райгородского (раскраски плоскости и пространства), «Математика живого» (динамика популяций, морфогенез, уравнение Тьюринга) и «В поисках размерности». Ещё квиз «Фракталы в природе» из девяти вопросов, галерея девяти фракталов, станция фрактальных замощений «Фрактал-Ателье», копия закрытого open call и предварительная программа следующего события `singularnost/`.

Зрители брали отсюда программу, билеты через виджет TimePad и карту площадок, организаторы — редактор программы. Сайт написан вручную на HTML, CSS и JS. Скорость проверяют скрипты и workflow: после каждого значимого пуша отчёт PageSpeed коммитится в `.pagespeed/`. Работа велась арками (`COWORK.md`, `ARKA.md`, история в `zhurnal/SVODKI.md`).

Основная сборка шла в мае 2026, последняя версия программы — 22.05. После фестиваля была одна арка, 09.07: добавили квиз, потом его переоткрыли из-за неверной картинки №8 (плазменный шар вместо фигуры Лихтенберга). Открытыми остались сдвиг вёрстки на десктопе (CLS 0,377), ссылка с главной на квиз и замена картинки. Справка `.claude/CLAUDE.md` устарела: она ещё называет проект `matema-fest-2026` и ведёт на старый preview-репозиторий.

Сюда идти за слайдами лекций фестиваля, за квизом о фракталах, за устройством базы программы и её редактора (образец для следующего события) и за самим сайтом. Из репозиториев фестиваля живой сайт и лекции лежат именно здесь: `matema-fest-2026` — бриф для дизайна, `matema-fest-opencall` — первый дом домена, `gallery` — черновик галереи. Посты о фестивале для «Кроссворда Тьюринга» пишет скилл `fractal-odyssey-editor`. Папка `singularnost/` — заготовка события «Сингулярность» (10.10.2026, музей «Атом»), которое не состоялось.
