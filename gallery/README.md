# «Галерея самоподобных форм» — выставка девяти фракталов на одной странице

<!-- gen:podrobno — пишет генератор описаний; правки сюда пропадут, править ответы анкеты -->

Научпоп-выставка о фракталах, собранная к фестивалю «Фрактальная Одиссея» как одна веб-страница: «Девять экспонатов в хронологическом порядке: от множества Кантора до папоротника Барнсли. К 50-летию слова „фрактал“». README нет, репозиторий и есть сама страница.

Внутри `index.html` и обложка для превью. Экспонаты: множество Кантора, дерево Пифагора, треугольник Серпинского, папоротник Барнсли, снежинка Коха, ковёр Серпинского и губка Менгера, кривые Пеано и Гильберта, дракон Хартера — Хейтуэя, Аполлоновы упаковки. У каждого экспоната раскрываются слои «Детали» и «Формулы», рисунки живые, на canvas и SVG. Последний блок ведёт на фестиваль.

Страница для широкой аудитории без подготовки: сверху рассказ, формулы спрятаны во второй слой. Сделана вручную одним HTML-файлом. Адрес в разметке для соцсетей — `d1-d57.github.io/gallery/`, то есть страница, скорее всего, публиковалась на GitHub Pages.

Репозиторий прожил один день, 28.04.2026. Та же страница лежит в `matema-fest-opencall/gallery/` и в `matema-fest/gallery/`; от версии в `matema-fest` она отличается только двумя строками превью, которые там смотрят на `matema-fest.ru`. Похоже, здесь была черновая площадка, а живая копия встроена в сайт фестиваля.

Сюда идти (а лучше сразу в `matema-fest/gallery/`, там актуальная копия) за готовыми научпоп-описаниями классических фракталов для лекции, поста или новой выставки. Связи: `matema-fest`, `matema-fest-opencall` и «Фрактал-Ателье» (`matema-fest/atelie/`).
